# Contributing to Codefa Stories

Thank you for your interest in contributing.

## Development Workflow

1. Fork or clone the repository.
2. Create a feature or fix branch.
3. Make focused changes.
4. Run the required tests and quality checks.
5. Open a Pull Request against `main`.

## Branch Naming

Examples:

- `feature/story-viewer`
- `feature/elementor-widget`
- `fix/mobile-swipe`
- `security/comment-validation`
- `performance/story-query`

## Requirements

Contributions must follow:

- WordPress Coding Standards
- Secure coding practices
- Performance-focused development
- Accessibility best practices

Do not introduce unnecessary runtime dependencies.
