# Codefa Stories

A lightweight, secure, and performance-focused Stories plugin for WordPress.

> Codefa Stories is currently under active development and is not yet ready for production use.

## Goals

- Minimal performance overhead
- Security-first architecture
- Image and video stories
- Multi-slide stories
- Story comments and likes
- Optional WooCommerce product integration
- Optional Elementor widget integration
- Independent from themes and page builders
- Accessible and responsive frontend
- Open-source development

## Performance Principle

Codefa Stories should load no frontend assets or perform story-related queries on pages where Stories are not used.
